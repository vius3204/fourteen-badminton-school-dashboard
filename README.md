# Fourteen Badminton School Dashboard

Website dashboard untuk manajemen sekolah bulutangkis: kas, kehadiran, anggota, dan penilaian.

## Repository

- GitHub: https://github.com/vius3204/fourteen-badminton-school-dashboard

## Cara publish ke GitHub Pages

1. Buka repository di GitHub.
2. Pilih Settings.
3. Masuk ke Pages.
4. Atur:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Save.
6. Tunggu beberapa menit, lalu website dapat diakses di:
   https://vius3204.github.io/fourteen-badminton-school-dashboard/

## Catatan

Website ini dibuat sebagai static HTML dan dapat diakses langsung tanpa build tools. Untuk data yang tersimpan permanen, perlu dihubungkan ke Firebase atau backend lain.
